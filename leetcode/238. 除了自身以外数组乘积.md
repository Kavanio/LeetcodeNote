
## 解题代码

```java
public Solution{
	public int[] productExceptSelf(int[] nums) {
		int n = nums.length;
		
		int[] answer = new int[n];
		answer[0] = 1;
		
		for(int i = 1; i < n; i++) {
			
			answer[i] = answer[i - 1] * nums[i - 1];
		
		}
		
		int right = 1;
		
		for(int i = n - 1; i > 0; i--) {
			answer[i] = answer[i] * right;
			
			right = right * nums[i];
		}
		
		return answer;
	}
}
```

## 解题思路
这道题的的意思是说找到数组中，除了自身以外的这个数字，其它数字的乘积。
核心解题思路，就是：前缀和 + 后缀和。
也就是以这个数字为界限，将它前面的所有数字相乘，再将后面所有数字相乘，最后再乘在一起。
刚开始我们可以先统计一下每个数字的前缀和，再统计一下每个数字的后缀和，然后对应着乘起来即可。
前缀和统计的公式是：
```java
answer[i] = answer[i - 1] * nums[i - 1]
```
这个公式是如何得到的？
> 当前位置左边所有数的乘积 = 上一个位置左边所有数的乘积 × 上一个数。

这里我们直接将做前缀和统计在结果数组中，就不用重新开阔一个数组了。
然后统计后缀和的时候，使用一个变量`right` 统计当前数字的后缀和乘积。
然后从后向前遍历。
然后用当前位置的数字 `answer[i]` * `right` 就得到了当前位置的除了自身以外数组乘积。
然后更新一下`right`即可开启下一轮遍历。
更新`right`的时候就使用当前数字右侧那个数字的后缀和，也就是 `right` 乘以当前位置的数字即可。
一句话总结就是：
**先把左边的乘积保存到 answer，再从右往左把右边的乘积乘进去。**
