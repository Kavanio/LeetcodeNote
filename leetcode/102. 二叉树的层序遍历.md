
## 解题代码
```java
class Solution {
	public List<List<Integer>> levelOrder(TreeNode root) {
		List<List<integer>> result = new ArrayList<>();
		if(root == null) return result;
		
		Queue<TreeNode> queue = new ArrayDeque<>();
		queue.offer(root);
		
		while(!queue.isEmpty()) {
			// 计算队列中有多少个元素
			int size = queue.size();
			List<Integer> current = new ArrayList<>();
			
			for(int i = 0; i < size; i++) {
				// 从队头取出节点
				TreeNode node = queue.poll();
				
				current.add(node.val);
				
				// 将下一层节点加入队列
				if(node.left != null) {
					queue.offer(node.left);
				}
				if(node.right 1= null) {
					queue.offer(node.right);
				}
			}
			result.add(current);
		}
	}
	return result;
}
```


## 解题思路
这道题的解法使用：**队列实现BFS**

为什么使用队列？
因为队列具有先进先出的特点。可以理解成排队打饭：先来的人先处理，后面来的人只能排在队尾。
放到二叉树中也是同样的道理：
1. 先把根节点加入队列
2. 每次取出队头，记录它的值
3. 如果它有左右孩子，就一次加入队尾。
4. 不断重复，知道队列为空。

**最关键的地方：如何区分每一层？**
仅仅使用队列，只能得到：1 → 2 → 3 → 4 → 5
因此我们还需要知道**每一层取出多少个节点**
在开始处理某一层之前，先记录队列的长度。
例如：

```
queue = [2, 3]

size = 2
```

这就意味着当前层只有两个节点需要处理。

然后使用：

```
for (int i = 0; i < size; i++)
```

只处理这两个节点。
执行过程：

| 操作     | queue     | current |
| ------ | --------- | ------- |
| 开始     | [2, 3]    | []      |
| 取出 2   | [3]       | [2]     |
| 加入 4、5 | [3, 4, 5] | [2]     |
| 取出 3   | [4, 5]    | [2, 3]  |
| 本层结束   | [4, 5]    | [2, 3]  |
**特别需要注意**
虽然处理节点2的时候加入了 4、5，但是之前记录的 size = 2 不会改变。
所以当前 for 循环只会执行俩次。
节点 4、5 会留到下一轮 while 再处理。
这就实现了不同层之间的区分。

**为什么使用while和for俩层循环？**
- while：负责一层一层的遍历
- for：负责把当前这一层的所有节点处理完
