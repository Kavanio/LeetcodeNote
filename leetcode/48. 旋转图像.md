## 解题代码
```java
class Solution {
	public void rotate(int[][] matrix) {
		int n = nums.length;
		
		for(int i = 0; i < n; i++) {
			for(int j = i + 1; j < n; j++) {
				int temp = matrix[i][j];
				matrix[i][j] = matrix[j][i];
				matrix[j][i] = temp;
			}
		}
		
		for(int i = 0; i < n; i++) {
			int left = 0;
			int right = n - 1;
			
			while(left < right) {
				int temp = matrix[i][left];
				matrix[i][left] = matrix[i][right];
				matrix[i][right] = temp;
			}
			
			left++;
			right--;
		}
	}
}
```


## 解题思路
这道题的意思是：给一个 n ✖️ n 的二维矩阵，需要将矩阵顺时针旋转 90度，并且要求原地修改不能重新开一个二维数组。
这道题的核心解题思路就是：
>先转置矩阵，再将每一行左右翻转

所谓转置，就是将：
```java
matrix[i][j] -> matrix[j][i]
```
进行交换。
转置的时候，j 要从 i + 1开始：
```java
for(int j = i + 1; j < n; j++){}
```
因为只需要处理主对角线一侧的元素，否则同一组元素会交换俩次，最后又变回原来的位置。
所以这道题最核心的记忆点就是：
> 顺时针旋转 90度 = 主对角线转置 + 每一行左右翻转
