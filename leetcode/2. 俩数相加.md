
## 解题代码
```java
class Solution {
	public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
		ListNode dump = new ListNode(0);
		ListNode head = dump;
		
		int carr = 0;
		ListNode p1 = l1, p2 = l2;
		
		while(p1 != null || p2 != null || carr != 0) {
			int sum = carr;
			
			if(p1 != null) {
				sum += p1.val;
				p1 = p1.next;
			}
			if(p2 != null) {
				sum += p2.val;
				p2 = p2.next;
			}
			
			carr = sum / 10;
			head.next = new ListNode(sum % 10);
			head = head.next;
		}
		
		return dump.next;
	}
}
```

## 解题思路
首先这道题的题目意思大概是：
给你俩个链表：
- 2 -> 3 -> 4：代表的正整数是：432
- 3 -> 4 -> 5：代表的正整数是：543
最后要返回俩个正整数相加之后的逆序链表，也就是：9 -> 7 -> 5。

那么我想到的解题思路就是，创建一个虚拟头节点，然后循环遍历俩个链表，将俩个位置上的数字累加起来，然后通过一些计算，追加到虚拟头节点的后面，最后直接返回虚拟头节点的下一位即可。
首先要引用一个变量 `carr` 处理特殊情况，也就是进位的情况，例如：
5 + 7 = 12，那么这一位上的数字很显然只保留2，然后下一位需要累加1，然后carr就是用来保存这个1的，下一位在计算sum总和的时候就会累加上这个1。
而真正要拼接的2，是通过 sum % 10得出来的，例如：12 % 10 = 2、4 % 10 = 4。
关于while循环条件：`while(p1 != null || p2 != null || carr != 0)`
其中如果俩个链表的长度不一致，只要其中还有一个链表还不为null，循环就会一直进行下去，到最后来个链表的遍历完了，carr 无法计算的到了，等于0，此时循环就会终止结束。
至于为什么while循环内部还需要进行一次非空判断，就是防止俩个链表长度不一致的时候，出现空指针异常。
