
## 解题代码
```java
class Solution {
	public int maxDepth(TreeNode root) {
		// 如果当前节点为空，返回深度 0
		if(root == null) {
			return 0;
		}
		
		// 让左子树计算自己的最大深度
		int left = maxDepth(root.left)
		
		// 让右子树计算自己的最大深度
		int right = maxDepth(root.right);
		
		// 选择更深的一边，加上自己这一层
		return Math.max(left, right) + 1;
	}
}
```

## 解题思路

其实我的理解就是每个节点要处理的事情就是，让自己左子树计算出来左边的最大深度，然后让右子树计算出来右边的最大深度，完事之后 + 1，然后将这个结果回报给上一层。
这似乎就是一套工作流水线，每个节点要处理的事情都相同，所以这道题使用递归。

### 递归是怎么工作的？

可以把递归理解成：自己暂时不会算，就先让下面的人算，下面的人算好以后，再把结果告诉自己。
