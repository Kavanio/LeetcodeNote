
## 解题代码
```java
class Solution {

	public List<List<Integer>> threeSum(int[] nums) {
		Arrays.sort(nums);
		List<List<Integer>> result = new ArrayList<>();
		for (int i = 0; i < nums.length; i++) {
		
		if (i > 0 && nums[i] == nums[i - 1]) {
			continue;
		}
		int left = i + 1;
		int right = nums.length - 1;
	
		while (left < right) {
			int sum = nums[i] + nums[left] + nums[right];
			if (sum == 0) {
				result.add(Arrays.asList(
					nums[i],
					nums[left],
					nums[right]));
				while (left < right && nums[left] == nums[left + 1]) {
					left++;
				}
				while (left < right && nums[right] == nums[right - 1]) {
					right--;	
				}
				left++;
				right--;
			
			} else if (sum < 0) {
				left++;
			} else {
				right--;
			}
			}
		
		}
		return result;
	}

}
```


## 解题思路
这道题说是找三数之和，但是转念一想，我们可以固定一个数字，然后去找其它俩个数之和，所以就变成了“找俩数之和”。
核心思路还是利用双指针解题思路，固定一个指针在起始位置，然后左指针在它位置后面一位，右指针在最末尾。
通过移动 left 指针和 right 指针，向中间不断寻找是否和第一个指针 i 和为0。
当然这个过程中可能会出现重复的，所以这道题最重要的就是去重。
一句话来说就是看见相同的我们就跳过，例如第一个指针 i，刚开始的位置索引0上是`-1` 但是这一轮遍历之后到下一轮之后索引`1`上还是 `-1` 所以我们果断跳过向后。
left 指针和 right 指针同样也是这个道理。

---
同时需要注意的就是，当固定了一个数字 i 之后，每找到一组三元组之后，满足条件的话就要移动：left 和 right，继续向中间靠拢，继续寻找。
再移动的时候需要注意的是，需要跳过与上一个数字相同的数字。
```java
left: nums[left] == nums[left + 1];
right: nums[right] == nums[right - 1];
```
如果遇到相同的就要跳过当前数字。
