
## 解题代码
```java
class Solution {
	public boolean hasCycle(ListNode head) {
		ListNode slow = head;
		ListNode fast = head;
		
		while(fast != null && fast.next != null) {
			slow = slow.next;
			fast = fast.next.next;
			
			if(slow == fast) return true;
		}
		
		return false;
	}
}
```

## 解题思路
这道题主要使用的是快慢指针的思路。
想象一个环形跑道，一个人跑步速度快另一个人跑步速度慢，那么俩个人同时起跑，终会在一个点相遇，然后跑得快的那个会超过他。
那么环形链表也是一样的，只要链表存在环，那么俩个指针终会相遇，如果不存在环，那么快指针很快就跑到头了，fast.next == null。

- 为什么循环的条件是 fast != null && fat.next != null
因为fast本身一次需要走俩步 fast.next.next，如果fast 本身为 null，活着 fast.next = null，可能会发生空指针异常。


- 注意
**快慢指针相遇的点不一定就是环的入口**
