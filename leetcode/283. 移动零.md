
## 解题代码
```java
class Solution {

	public void moveZeroes(int[] nums) {
	
		int slow = 0;
		
		  
		
		for(int i = 0; i < nums.length; i++) {
		
			if(nums[i] != 0) {
			
				int temp = nums[i];
				
				nums[i] = nums[slow];
				
				nums[slow] = temp;
				
				slow++;
			
			}
		
		}
	
	}

}
```

## 解题思路
这道题的核心解题思路就是，利用双指针。
慢指针指向数组中为0的那个索引，快指针则去寻找非0的那个数。
初始化设置慢指针为0
遍历数组，快指针向后寻找非0的数，找到之后，快慢指针上的数字交换位置，然后慢指针 +1 向前走一格。
一句话总结就是：`fast` 负责找非 0，`slow` 负责指向下一个该放非 0 的位置，找到后交换，让所有非 0 逐步挪到前面、0 留到后面。
