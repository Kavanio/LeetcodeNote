
## 解题代码
```java
class Solution {
	public int subarraySum(int[] nums, int k) {
		Map<Integer, Integer> map = new HashMap<>();
		map.put(0, 1);
		int count = 0;
		int prefixSum = 0;
		
		for(int num : nums) {
			// 累加当前前缀和
			prefixSum += num;
			
			// 查看之前有没有出现过 preifxSum - k
			if(map.containKeys(prefixSum - k)) {
				count += map.get(prefixSum - k);
			}
			
			// 记录当前前缀和出现的次数
			map.put(
				prefixSum,
				map.getOrDefault(prefixSum, 0) + 1
			);
		}
		
		return count;
	}
}
```

## 解题思路
这道题的核心解题思路就是“前缀和”。
例如数组是：[1, 2,3 ]
那么前缀和分别是：0，1，3，6。
而我们要找的就是数组中和为k的字数组个数，本质上就是统计前缀和。
如果我们要找的k是5。
那么我们只需要用 前缀和 - k，得出来的数字去数组中找，如果能找到，就说明数组中有符合的子数组。

map中存储的就是每个前缀和出现的次数。
每次用 prefixSum - k，得到不同的结果只需要去map中寻找，之前是否出现过，如果没有出现过，就将当前前缀和放入map数组中。
如果出现了，就从map中获取之前出现过的次数，因为不同位置都有可能出现一次。
