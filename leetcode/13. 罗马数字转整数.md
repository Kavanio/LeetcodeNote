## 解题代码
```java
public int romanToInt(String s) {
	Map<Character, Integer> map = new HashMap<>();
	map.put('I', 1);
	map.put('V', 5);
	map.put('X', 10);
	map.put('L', 50);
	map.put('C', 100);
	map.put('D', 500);
	map.put('M', 1000);
	
	int s_len = s.length();
	int result = 0;
	
	for(int i = 0; i < s_len; i++) {
		// 获取当前数字
		int curr_num = map.get(s.charAt(i));
		
		// 下一个数字，默认给0
		int next_num = 0;
		if(i + 1 < s_len) {
			next_num = map.get(s.charAt(i + 1));
		}
		
		// 如果左侧的字符数小于右侧的右侧数
		/**
		example: IV -> 4
		0 + 5 = 5
		5 - 1 = 4
		**/
		if(curr_num < next_num) {
			// 用结果 - 当前数 再累加
			result -= curr_num;
		} else {
			result += curr_num;
		}
	}
	
	return result;
}
```

## 解题思路

> 核心思路就是处理“小数字在大数字左边”的减法操作
