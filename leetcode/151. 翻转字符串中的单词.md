
## 解题代码
```java
public String resversWord(String s) {
	// 1.去除空格，得到干净的字符串
	StringBuilder sb = trimSpace(s);
	
	// 2.翻转整个字符串
	resverse(sb,0,sb.length() - 1);
	
	// 3.翻转每个单词
	resverseEachWord(sb);
	
	return sb.toString();
}

private StringBuilder trimSpace(String s) {
	
	// 1.去除首尾空格
	s = s.trim();
	
	// 2.压缩中间空格
	StringBuilder sb = new StringBuilder();
	for(int i = 0; i < s.length(); i++) {
		char c = s.charAt(i);
		// 如果当前字符或者上一个字符不为空
		if(c != ' ' || sb.charAt(sb.length() - 1) != ' ') {
			sb.append(c);
		}
	}
	
	return sb;
}

private void resverse(StringBuilder sb, int left, int right) {
	while(left < right) {
		char temp = sb.charAt(left);
		
		sb.setCharAt(left,sb.charAt(right));
		sb.setCharAt(right,temp);
		
		left++;
		right--;
	}
}

private void resverseEachWord(StringBuilder sb) {
	int len = sb.length();
	int start = 0, end = 0;
	
	while(start < len) {
		while(end < len && sb.charAt(end) != ' ') {
			end++;
		}
		
		resverse(sb,start, end - 1);
		start = end + 1;
		end = start;
	}
}
```

## 解题思路
> 首先整体翻转字符串，然后再挨个翻转其中的每个单词
> 1. 先去除首尾空格，并且还需要去除多余的空格，要确保每个单词中间只能用一个空格分开
> 2. 整体翻转字符串
> 3. 挨个翻转每个单词
> 	- 使用双指针，start负责记录字符串中每个单词的开始，end则不断向后去寻找每个单词的结尾，也就是空字符串
> 	- end找到这个位置之后，只需要翻转start ～ end - 1中间的字符即可，也就是翻转成功了一个单词
> 	- 然后需要调整一下俩个指针的位置，start调整到end后面一位，因为每个单词使用一个空字符分割的，所以后面一位就是下一个单词的开始，end同样也是重置到start，开始重新向后去寻找下一个单词的结尾
