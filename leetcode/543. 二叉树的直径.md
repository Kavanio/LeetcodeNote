
## 解题代码
```java
class Solution {
	
	int diameter = 0;
	
	public int diameterOfBinaryTree(TreeNode root) {
		depth(root);
		
		return diameter;
	}
	
	private int depth(TreeNode node) {
		// 空节点深度 = 0
		if(node == null) {
			return 0;
		}
		
		// 分别递归计算左右子树深度
		int left = depth(node.left);
		int right = depth(node.right);
		
		// 更新经过当前节点的最大路径
		diameter = Math.max(diameter, left + right);
		
		// 返回当前子树的最大深度
		return Math.max(left, right) + 1;
	}
}
```

## 解题思路

首先考虑一个问题：
**如果最长路径刚好经过某个节点，那么这条路径有多长？**
例如：

```
          2
         / \
        4   5
       /     \
      6       7
     /
    8
```

假设最长路径经过节点 `2`，那么它一定是从左子树的某个节点出发，经过节点 `2`，再走到右子树的某个节点。
例如：
```
8 → 6 → 4 → 2 → 5 → 7
```
这条路径一共经过 5 条边。

我们可以发现：**经过某个节点的最长路径 = 左子树最大深度 + 右子树最大深度**
这里递归计算的深度采用节点数量：空节点深度为0，叶子节点深度为1.因此，左右子树的深度相加，正好等于经过当前节点的最长路径边数。
这里还需要注意：**最长路径不一定经过根节点**
所以不能只计算根节点的左右子树深度，而是要在递归过程中，**把每个节点都当作最长路径可能经过的位置，计算一次直径，并不断更新最大值**

注意注意的是：
- left + right：计算经过当前节点的最长路径，用来更新答案。
- Math.max(left, right) + 1：计算当前子树的最大深度，用来返回给父节点。


```
        1
       / \
      2   3
     / \
    4   5
```

```
depth(1)
    |
    |-- depth(2)
    |      |
    |      |-- depth(4)
    |      |      └── 返回 1
    |      |
    |      |-- depth(5)
    |      |      └── 返回 1
    |      |
    |      |-- left = 1, right = 1
    |      |-- diameter = 2
    |      └── 返回 2
    |
    |-- depth(3)
    |      └── 返回 1
    |
    |-- left = 2, right = 1
    |-- diameter = 3
    |
    └── 返回 3
```
