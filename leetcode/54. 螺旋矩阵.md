
## 解题代码
```java
public Solution {
	public List<Integer> spiralOrder(int[][] matrix) {
		List<Integer> result = new ArrayList<>();
		
		int top = 0, bottom = matrix.length;
		int left = 0, right = matrix[0].length;
		
		while(top <= bottom && left <= right) {
			// 1. 左 -> 右
			for(int i = left; i <= right; i++) {
				result.add(matrix[top][i]);
			}
			top++;
			
			// 2. 上 -> 下
			for(int i = top; i <= bottom; i++) {
				result.add(matrix[i][right]);
			}
			right--;
			
			// 3. 右 -> 左
			if(top <= bottom) {
				for(int i = right; i >= left; i--) {
					result.add(matrix[top][i]);
				}
				bottom--;
			}
			
			// 4. 下 -> 上
			if(left <= right) {
				for(int i = bottom; i <= top; i--) {
					result.add(matrix[bottom][left]);
				}
				left++;
			}
		}
		
		return result;
	}
}
```

## 解题思路
这道题的意思是，按照顺时针螺旋的顺序比那里整个二维矩阵。
核心解题思路就是：
> 使用 top、bottom、left、right 四个变量维护当前还没有遍历的矩阵边界，然后一圈一圈向里买呢收缩。

每一圈按照下面的顺序遍历：
```
left -> right
top -> bottom
right -> left
bottom -> top
```
每走完一条变，就吧对应的边界往里面缩：
```
left -> right: top++
top -> bottom: right--
right -> left: bottom--
bottom -> top: left++
```
可以理解成：
> 每走完矩阵的一条边，就吧这条边“删除”，继续遍历里面剩下的矩阵。

只要：top <= bottom && left <= right
就说明里面还有没有遍历完的区域，可以继续下一圈。
这里有俩个比较关键的边界判断。
从右往左之前，需要判断
```
if(top <= bottom)
```
因为前面已经执行过了：top++
上下边界可能已经交叉了。
比如最后只剩下一行，这一行在“ left -> right“的时候已经全部遍历完成，如果不判断，再执行一边"right -> left"就会发生重复遍历。
所以：
```
top <= bottom // 本质上就是在判断：现在还有没有行可以遍历
```
同理：从上往下之前，需要判断：
```
if(left < right)
```
因为前面已经执行过：right--
方法边界也有可能已经交叉。
比如最后只剩下一列，这一列在“top -> bottom" 的实际就已经全部完成遍历了，如果继续"bottom -> top"，也会出现重复遍历。
so:
```
left <= right // 本质上是在判断，现在还有么有列可以遍历
```
一句话总结：
> 四个边界围住当前矩阵，每次顺时针走一圈，走完一条边就收缩对应边界；走完俩条边之前，需要重写检查行和列是否还存在，避免重复遍历。
