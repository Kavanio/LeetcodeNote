
## 解题代码
```java
public Sloution {
	public TreeNode invertTree(TreeNode root) {
		fn(root);
		
		return root;
	}
	
	private void fn(TreeNode root) {
		if(root == null) {
			return;
		}
		
		TreeNode temp = root.left;
		root.left = root.right;
		root.right = temp;
		
		fn(root.left);
		fn(root.right);
	}
}
```

## 解题思路

最开始我是从递归的思想出发的：**将一个大任务拆分成多个小人物。**
整个大任务就是翻转一颗二叉树。
那么如把它拆成小任务呢？
仔细观察可以发现，翻转整棵二叉树，其实就是让每个节点都完成同样的操作。
**交换当前节点的左右孩子**
例如：

```
       1
      / \
     2   3
```

对于节点 `1`，我只需要把节点 `2` 和节点 `3` 交换。
但是，如果节点 `2` 和节点 `3` 下面还有孩子，那么仅仅交换它们的位置是不够的。
所以，还需要让左右子树分别执行相同的翻转操作。
这就可以使用递归来解决。


### 递归具体是怎么工作的？

可以把它理解成一种任务分工：
假设我是根节点 `1`，我的任务是翻转整棵树。
但我不需要亲自处理下面所有节点，只需要：
1. 交换自己左右两个孩子的位置。
2. 让左孩子负责翻转它自己的子树。
3. 让右孩子负责翻转它自己的子树。
4. 等左右子树都翻转完成，当前这棵树也就翻转完成了。

而左右孩子又会继续按照相同的规则，将任务交给更下面的节点。
直到遇到空节点，递归才会停止。

**所以递归的关键，不是自己把所有事情做完，而是只处理当前节点该做的事情，再把剩余的同类问题交给递归。**
