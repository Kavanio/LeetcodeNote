
## 解题代码
```java
class Solution {
	public boolean detectCycle(ListNode head) {
		ListNode slow = head;
		ListNode fast = head;
		
		while(fast != null && fast.next != null) {
			slow = slow.next;
			fast = fast.next.next;
			
			if(slow = fast) {
				ListNode p = head;
				while(p != slow) {
					p = p.next;
					slow = slow.next;
				}
				return p;
			}
		}
		
		return null;
	}
}
```


## 解题思路
这道题与 141 题不同的是，141 题只让判断是否存在环，而 142 题是要找到环的入口。
核心思路：快慢指针，分俩步找到环的入口。
首先，慢指针每次走一步，快指针每次走俩步，如果俩者相遇则存在环；
然后将一个指针放回头节点，另一个留在相遇点，俩者每次都走一步，再次相遇的位置就是环的入口。
这是因为头节点到入口的距离，等于第一次相遇点沿环走到入口的距离（允许相差整圈）。
如果快指针走到 null，说明没有环，返回 null

*原理*
假设头节点到环入口的距离是 a，环入口到第一次相遇点的距离是 b，环的长度是 c。
因为快指针的速度是慢指针的俩倍，所以相遇的时候，快指针比慢指针多走的距离一定是环长的整数倍，由此可以推出：a + b = kc，其中 k 是整数。
因此，头节点到入口的距离 a，敲好等于相遇点沿着环走到入口的距离（允许多绕整圈）。
所以俩个指针从这俩个位置以相同速度出发，最终会在入口相遇。
*比喻*
把环想象成操场跑道，一个人从操场外的起点走向入口，另一个人从跑道上的相遇点出发。虽然他们的起点不同，但由于慢指针第一次相遇时形成的距离关系，俩个人到入口所需的步数恰好相同，因此同时到达入口。
