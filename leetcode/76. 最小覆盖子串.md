
## 解题代码
```java
public Solution {
	public String minWindow(String s, String t) {
		if(s.length() < t.length()) return "";
		
		Map<Character, Integer> need = new HashMap<>();
		Map<Character, Integer> windows = new HashMap<>();
		
		// 统计 t 中每个字符出现的次数
		for(char c : t.toCharArray()) {
			need.put(c, c.getOrDefault(c, 0) + 1);
		}
		
		int left = 0, right = 0;
		int valid = 0;
		int start = 0;
		int minLen = Integer.MAX_VALUE;
		
		while(right < s.length()) {
			char current = s.chatAt(right);
			right++:
			
			// 如果当前字符是 t 中所需要的
			if(need.containsKey(current)) {
				windows.put(current, windows.getOrDefault(current, 0) + 1);
				
				// 如果当前字符数量刚好达到要求
				if(need.get(current).equals(windows.get(current))) {
					valid++;
				}
			}
			
			// 当窗口已经满足要求的时候, 开始收缩
			while(valid == need.size()) {
				// 更新最小窗口
				if(right - left < minLen) {
					minLen = right - left;
					start = left;
				}
			
				char d = s.charAt(left);
				left++;
				
				// 如果移除的是目标字符的话
				if(need.containsKey(d)) {
					// 移除之后这个字符就不够了
					if(windows.get(d).equals(need.get(d))) {
						valid--;
					}
					windows.put(d, windows.get(d) - 1);
				}
			} 
		}
		
		return minLen == Integer.MAX_VALUE
			? "" : s.substring(start, start + minLen);
	}
}
```

## 解题思路
这道题的核心解题思路就是，利用滑动窗口。
和 438 题不同的是，这道题的滑动窗口大小不是固定的，而是需要不断的扩大和缩小。
首先使用`need`统计字符串`t`中每个字符需要出现的次数，再使用`windows`统计当前窗口中这些字符出现的次数。
定义左右俩个指针`left`and `right`
`right` 指针不断向右扩大窗口，当遇到`t`中需要出现的字符的时，就更新`window`中对应字符的数量。
如果某个字符在窗口中的数量刚好达到了`need`中的要求数量，就说明这个字符已经满足要求了，则`valid + 1`。
当 `valid == need.size()` 时，就说明当前窗口中已经完全覆盖了`t` 中所有需要的字符。
这个时候就不能再继续扩大窗口了，而是开始移动`left`指针缩小窗口，尽可能寻找一个更短的合法子串。
在缩小窗口的过程中，如果当前窗口长度比之前记录的最小长度还小，就更新`minLen`and `start`。
其中`left`移除某个字符之后，导致这个字符数量不再满足要求，就将`valid - 1`,停止缩小窗口，然后继续让`right`向右移动寻找新的合法窗口。
一句话总计就是：
right 负责扩大窗口把字符找齐，left 负责在满足条件之后不断压缩窗口，过程中记录最短的合法子串。
