## 解题思路
这道题核心思路就是：利用 HashSet 去重并快速查找数字是否存在，并且只从连续序列的起点开始查找。

1. 先把数组中所有的数字放入 HashSet 中，一是为了之后方便快速的查找一个数字是否存在，二是去重。
2. 遍历 Set 中每个 num
3. 判断 num - 1 是否存在，如果存在说明，num 并不是连续序列的起点，因为它前前面还有数字；
	如果不存在，则说明 num 是连续序列的起点，因为它前面已经没有数字了
4. 从这个起点开始判断 num + 1 是否存在，并且更新 currentLength 的长度
5. 最后比较一下 maxLength和 currentLength 的大小返回 maxLength即可。
	最后比较一下的原因是因为，数组中可能不止有一个连续的序列。所以要找出最长的那个连续序列。
