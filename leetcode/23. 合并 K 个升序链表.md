## 解题代码
```java
class Solution {
	public ListNode mergeKLists(ListNode[] lists) {
		if(lists == null || lists.length == 0) return null;
		
		return mergeSort(lists, 0, lists.length - 1);
	}
	
	private ListNode mergeSort(ListNode[] lists, int left, int right) {
		// 只剩一条链表的时候，它本身时有序的
		if(left == right) {
			return lists[left];
		}
		
		// 找到数组中间位置
		int mid = left + (right - left) / 2;
		
		// 递归合并左半部分
		ListNode l1 = mergeSort(lists, left, mid);
		// 递归合并右半部分
		ListNode l2 = mergeSort(lists, mid + 1, right);
		
		return merge(l1, l2);
	}
	
	private ListNode merge(ListNode l1, ListNode l2) {
		ListNode dummy = new ListNode(0);
		ListNode tail = dummy;
		
		while(l1 != null && l2 != null) {
			if(l1.val < l2) {
				tail.next = l1;
				l1 = l1.next;
			} else {
				tail.next = l2;
				l2 = l2.next;
			}
			
			tail = tail.next;
		}
		
		tail.next = (l1 != null) ? l1 : l2;
		
		return dummy.next;
	}
	
}
```

## 解题思路
最容易想到的解题思路，就是先把前俩条链表合并，然后再拿合并后的链表和第三条链表进行合并，一直重复下去。
这种方法虽然可以解决问题，但是有一个缺点：**随着合并的次数增加，前面合并好的链表会越来越长，导致一些节点被反复遍历**。
所以可以借鉴 148 题的归并思想，也就是**分治：先拆分后合并**。
不过俩道题有一个重要的区别：
- 148 题：把一条链表不断拆成更小的俩表，知道只剩下一个节点。
- 23 题：把存放K条链表的数组不断分成俩组，知道每组只剩下一个链表。

为什么这道题只需要拆到只剩下一条链表？
因为题目告诉我们了，每条链表本身就是有序的，所以没有必要继续拆分节点。

整个过程其实就是 **不断把多条链表分成俩组，再利用合并俩个有序链表的方法，把他们逐层合并起来**

### 递归是怎么执行的？
也就是 ==🔴mergeSort()==
首先，left 和 right 表示的是数组的下标，而不是链表的节点。
假设有4条链表：
```
下标： 0    1    2    3
      ↓    ↓    ↓    ↓
      L1   L2   L3   L4
```
第一次调用：
```java
mergeSort(lists, 0, 3);
```
表示需要将数组中下标 0 ~ 3 的四条链表合并成一条。
计算中点：
```java
int mid = left + (right - left) / 2;
// 0 + (3 - 0) / 2 = 1
```
此时 mid = 1，于是将数组分成俩组：
```java
ListNode l1 = mergeSort(lists, 0, 1);
ListNode l2 = mergeSort(lists, 2, 3);
```
程序会先执行第一行，进入左半部分的递归。
此时处理的是 L1 和 L2，由于还有俩条链表，所以继续拆分：
```java
mergeSort(lists, 0, 0); // L1
mergeSort(lists, 1, 1); // L2
```
这时候 left == right，出发递归终止条件。
因为范围里只剩下一条链表，而它本上就是有序的，所以很直接返回这条链表的头节点。
然后程序回到上一层递归，并执行：
```java
return merge(l1, l2);
```
此时就是将 L1 和 L2 合并。
并且这条链表的头节点回返回给更上一层递归。
之后也就是如上同理。
最后将左右来条有序链表合并，就得到最后的结果。
所以这道题的递归过程也可以理解成：**递归往下走的时候，不断缩小需要处理的链表范围；递归往回返回的时候，不断把俩条有序链表合并成一条更长的有序链表**
