## 解题代码
```java
public String longestCommonPrefix(String[] strs) {

	int len = strs.length;
	
	  
	
	if(strs == null || len == 0) {
	
		return "";
	
	}
	
	  
	
	String first = strs[0];
	
	  
	
	for(int i = 0; i < first.length(); i++) {
	
		char current_c = first.charAt(i);
		
		for(int j = 1; j < len; j++) {
		
			String other = strs[j];
			
			if(i >= other.length() || other.charAt(i) != current_c) {
			
				return first.substring(0,i);
			
			}
	
		}

	}

  

	return first;

}
```

## 解题思路
> 我们要把这个字符串数组想象成：
> 每一个字符左对齐，然后纵向排列
> example：
> 	first
> 	feat
> 	...
> 然后用第一个字符串作为基准，遍历每一个字符从上到下挨个比较
> 如果遇到索引越界了，也就是 i 超过了别的字符的长度或者当前字符和别的字符串上的字符不一样，那么说明0 - i，就是当前的最长公共前缀，因为这个字符串不满足，所以导致就算后面的字符串有满足的，也没有用了
