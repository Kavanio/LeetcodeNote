class Solution {
	public boolean searchMatrix(int[][] matrix, int target) {
		int n = matrix.length; // 有多少行
		int m = matrix[0].length; // 有多少列
		int row = 0; // 位于哪一行
		int col = n - 1; // 位于哪一列
		
		
		// 起点：矩阵右上角
		while(row <= n && col >= 0) {
			int current_num = matrix[row][col];

				return true;
			} else if (current_num > target) {
				// 横坐标向左移动

## 解题思路
题目意思简单来说：就是判断一个目标值是否存在与矩阵中。
但是题目说了：每行的元素从左到右是升序排列，每列的元素从上到下升序排列。
既然这么说了，我们就可以知道俩个信息点：
1. 矩阵左上角的数字是矩阵中最小的数字
2. 矩阵由上角的数字是矩阵中最大的数字
所以只有右上角的数字满足一大一小：
往左是变小，往下是变大。
所以我们遍历的起点就是从右上角开始。
然后先对比第一行，如果发现当前遍历的数字比目标值大的话，横坐标就往左移动 -> "col--"。
如果发现当前遍历的数字比目标值小的话，就开始往下遍历 -> "row++"。
直到遇到目标值才返回真。
一句话总结：
二维矩阵搜索问题，重点不是遍历，而是找到一个同事利用行列递增性质的起点，让每一步排除一整行或一整列。
