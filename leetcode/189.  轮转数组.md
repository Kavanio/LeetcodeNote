
## 解题代码
```java
class Solution{
	public void rotate(int[] nums, int k) {
		int n = nums.length;
		
		int k = k % n;
		
		// 1. 整体反转
		reverse(nums, 0, n - 1);
		
		// 2. 反转前 k 个
		reverse(nums, 0, k -1);
		
		// 3. 反转剩下
		reverse(nums, k, n - 1);
	}
	
	private void reverse(int[] nums, int left, int right) {
		while(left < right) {
			int temp = nums[left];
			
			nums[left] = num[right];
			nums[right] = temp;
			
			left++;
			right--;
		}
	}
}
```

## 解题思路
这道题的核心思路就是，把数组最后 k 个元素移动到数组最前面。
可以利用三次反转做到原地修改。
首先通过
```java
k %= nums.length;
```
避免 k 大于数组长度，做多余无效的移动。
然后先将整个数组反转，这要原本最后的 k 个元素就会跑到数组前面去，但是它们内部的顺序是反的。
所以再把前 k 个元素反转一次，恢复它们原来的顺序。
最后将剩下的元素反转一次，恢复剩余部分的顺序。
一句话总结就是：
> 先整体反转把后 k 个搬到前面，再分别反转前后俩部分，把各自的顺序恢复回来。
