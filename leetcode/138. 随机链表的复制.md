
## 解题代码
```java
class Solution {
	public Node copyRandomList(Node head) {
		
		if(head == null) {
			return null;
		}
		
		// 原节点和新节点之间的映射关系
		Map<Node, Node> map = new HashMap<>();
		Node curr = head;
		// 第一次遍历，复制所有节点，建立映射关系
		while(curr != null) {
			Node newNode = new Node(curr.val);
			map.put(curr, newNode);\
			
			curr = curr.next;
		}
		
		curr = head;
		while(curr != null) {
			// 从 map 中获取前一次循环创建好的新节点
			Node copy = map.get(curr);
			
			// 根据原始链表的对应关系从 mpa 中依次获取，并赋值
			copy.next = map.get(curr.next);
			cop.random = map.get(curr.random);
			
			curr = curr.next;
		}
		
		// 返回新链表的头节点
		return map.get(head);
	}
}
```

## 解题思路
> 题目要求我们对一条特殊的链表进行深拷贝，并返回深拷贝后的链表


一开始，我想到的是按照普通的链表复制方式，遍历原始链表，每遇到一个节点，就创建一个值相同的新节点，再通过 tail.next 将它连接起来。
但是很快就会发现一个问题：
**普通链表可以顺序复制，但是 random 可能指向的是后面尚未创建的节点**

那么我想的话就是，先遍历将所有的节点都创建出来之后再统一处理指针。
所以可以利用 HashMap 建立映射关系，map 的 key 是原始链表的节点，对应的则是新创建出来的节点，这样之后就可以通过 map.get(curr) 获取到新的节点了。

于是整个过程可以分成俩次遍历：
**第一次遍历：创建所有新节点**
**第二次遍历：连接 next 和 random**
这里最关键的两行代码：
```java
copy.next = map.get(curr.next);
```
假设当前 curr 指向原始节点A：
```
A.next -> B
```
那么 curr.next 得到原始节点 B，而 map.get(B)，就可以得到新节点B‘。

```java
copy.random = map.get(curr.random);
```
和上面类似。

所以整个解法的核心就是：**利用 HashMap，把原链表中的节点引用转换成新链表中的节点引用**
