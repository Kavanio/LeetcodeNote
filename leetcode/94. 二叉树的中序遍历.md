
## 解题代码
```java
class Solution {
	public List<Integer> inorderTraversal(TreeNode root) {
		List<Integer> result = new ArrayList<>();
		
		inorder(root, result);
		
		return resultl;
	}
	
	private void inorder(TreeNode root, List<Integer> result) {
		// 递归终止条件
		if(root == null) {
			return;
		}
		
		// 1. 先遍历左子树
		inorder(root.left, result);
		
		// 2. 记录当前节点
		result.add(root.val);
		
		// 3. 最后遍历右子树
		inorder(root.right, result);
	}
}
```

## 解题思路
所谓中序遍历，处理顺序就是： 左子树 -> 当前节点 -> 右子树。

这道题可以使用递归的解题思路。
可以把它想象成一个人按照规定的路线检查房间。
假设每个节点都是一个房间，每进入一个房间，都必须完成三件事情：
1. 先去左边房间，把左边全部检查完
2. 左边检查完，记录当前房间的数字
3. 最后去右边的房间，把右边全部检查完

问题是，左边的房间可能还有自己左边的房间。
这时候不需要提前想好整棵树怎么走，只需要让每个房间都执行同样的规则。
这就是递归的核心：把一个大问题交给同样的方法去处理更小的问题，处理完再回来继续。

其实我觉得，代码中的记录当前节点，实际上就是每次都把当前节点看做成是一个根节点，不管是去左边遍历还是右边。
为什么这样说呢？因为如果要记录当前值的前提是左子树为null的时候，记录下当前节点的值。
