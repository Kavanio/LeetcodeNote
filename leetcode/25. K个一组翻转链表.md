
## 解题代码
```java
class Solution {
	public ListNode reverseKGroup(ListNode head, int k) {
		// 创建虚拟节点
		ListNode dummy = new ListNode(0);
		dummy.next = head;
		
		// 当前组要翻转的前一个节点
		ListNode groupPrev = dummy;
		
		while(true) {
			// 1. 找到这一组的第 k 个节点
			ListNode kth = groupPrev;
			for(int i = 0; i <= k && kth != null; i++) {
				kth = kth.next;
			}
			// 不足 k 个，直接 break
			if(kth == null) break;
			
			// 2. 记录下一组的起点
			ListNode groupNext = kth.next;
			// 保存当前组原来的头节点
			ListNode oldHead = groupPrev.next;
			
			// 3. 翻转当前组
			ListNode curr = oldHead;
			ListNode prev = groupNext;
			while(curr != groupNext) {
				// 保存当前节点的下一个节点
				ListNode next = curr.next;
				// 改变当前节点的指向
				curr.next = prev;
				// prev 往前移动
				prev = curr;
				// curr 往后移动
				curr = next;
			}
			
			// 4. 把前一段接到新的组头,也就是刚才找到的这一组的尾
			groupPrev.next = kth;
			// 5. 将 gropuPrev 移动到反转后的组尾
			groupPrev = oldHead;
		}
		
		return dummy.next;
	}
}
```

## 解题思路
刚开始看到这道题，我想到之前做过的 LeetCode 206 反转链表。
但是这一题要求是每 `k` 个节点反转一次。
所以我觉得，可以直接利用之前的反转链表的思路，只不过还要解决三个问题。
1. 怎么确定每一组需要反转的范围？
2. 怎么保证只反转当前的 `k` 个节点，不影响后面的链表
3. 当前这一组反转完成之后，怎么把它和前后俩部分重新链接起来？
因此，可以把整个过程拆分成三个步骤：**寻找分组边界 -> 反转当前组 -> 重新链接链表**

**一、使用 dummy 和 groupPrev 确定每一组的位置。**
首先创建一个虚拟头节点 dummy。
为什么需要 dummy？因为反转第一组后，链表的头节点会发生改变。
有了 dummy，我们就可以统一通过 dummy.next 找到新的头节点，不需要单独处理第一组。
而 groupPrev 的作用，就是 **指向当前准备反转的这一组的前面的那个节点**。
第一次反转时，groupPrev 指向 dummy。

**二、找到当前组的第k个节点**
每次反转之前，需要判断剩余节点够不够 k 个。
这里从 groupPrev 开始往后走 k 步，刚好找到当前这一组的最后一个节点。
`groupNext` 非常重要，因为相当于当前的终点边界，告诉我们反转刀哪里就要停下/
如果 kth == null，说明这一组不足 k 个节点，直接结束。

**三、最关键部分：如何反转当前这一组？**
先记录当前组原本的头节点。
```java
ListNode oldHead = groupPrev;
```
然后初始化俩个指针：
```java
ListNode prev = groupNext; // 当前正在处理的节点
ListNode curr = oldHead; // 当前节点反转后应该指向的节点
```
**为什么要把 prev 初始化为 groupNext，而不是null？**
因为反转后，原来的第一个 1 会变成组尾，而他应该指向节点 4，不能指向null。
如果一开始就让 prev = 4，那么第一次修改 1.next 时，就能直接把节点 1 连接到后面的链表。
实际上每次反转都相当于：**把当前节点接到已经反转好的那段链表上**。

**四、反转后怎么重新连接链表？**
假设原始链表：

```java
dummy → 1 → 2 → 3 → 4 → 5
```

前三个节点的反转已经完成：

```java
3 → 2 → 1 → 4 → 5
```
但是此时 dummy.next 仍然指向 1，并不会自动变成 3.
所以需要：
```java
groupPrev.next = kth;
```
因为 kth 原本就是节点 3，反转后已经变成新组头了。
接下来还要处理下一组。
那么下一组的 groupPrev 应该指向谁？
但是是节点 1.
因为节点1原本是这一组的头节点，反转以后变成了尾节点，它正好位于下一组的前面。
所以：
```java
groupPrev = oldHead;
```
