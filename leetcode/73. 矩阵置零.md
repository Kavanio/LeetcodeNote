```java
class Solution {
	public void setZeroes(int[][] matrix) {
		int m = matrix.length;
		int n = matrix[0].length;
		
		boolean firstColZero = false;
		
		for(int i = 0; i < m; i++) {
			if(matrix[i][0] == 0) {
				firstColZero = true;
			}
			
			for(int j = 1; j < n; j++) {
				if(matrix[i][j] == 0) {
					matrix[i][0] = 0; // 标记行
					matrix[0][j] = 0; // 标记列
				}
			}
		}
		
		for(int i = 1; i < m; i++) {
			for(int j = 1; j < n; j++) {
				if(matrix[i][0] == 0 || matrix[0][j] == 0) {
					matrix[i][j] = 0;
				}
			}
		}
		
		if(matrix[0][0] == 0) {
			for(int j = 0; j < n; j++) {
				matrix[0][j] = 0;
			}
		}
		
		if(firstColZero) {
			for(int i = 0; i < m; i++) {
				matrix[i][0] = 0;
			}
		}
	}
}
```

## 解题思路
这道题的意思是说：如果矩阵中的某一个位置是 0，那么这个 0 所在的整行和整列都要变成0。
这道题不能一边遍历一边直接置零，因为新产生的 0 会继续影响后面的判断。
比如原本只有一个 0 ，我们把它所载的行和列置零之后，就会产生很多新的 0，这些新的 0 并不是原始矩阵中的 0，所以不能再根据这些新的 0 继续扩散。
所以核心解题思路就是：
**先记录那些行、哪些列需要置零，最后再统一进行修改。**
直接使用矩阵中的第一列记录“哪些行需要置零”，使用第一行记录“哪些列需要置零”。
也就是当我们发现：
```java
matrix[i][j] == 0;
```
就记录：
```java
matrix[i][0] = 0;
matrix[0][j] = 0;
```
表示第 i 行以后需要全部置零、第 j 列 以后需要全部置零。
所以可以理解成：
```
第一列 = 行标记
第一行 = 列标记
```
然后第二次遍历矩阵内部区域的时候，只需要判断：
```java
if(matrix[i][0] == 0 || matrix[0][j] == 0) {
	matrix[i][j] = 0;
}
```
也就是说：
如果当前位置所在的行被标记了，或者说所在的列被标记了，那么当前位置就需要变成0。
这里第二次遍历是从：
```
i = 1;
j = 1;
```
开始。
因为第一行和第一列现在正在用来保存标记，不能提前把它们改掉。

这道题还有一个比较绕的地方就是：
```java
matrix[0][0]
```
因为它既属于第一行，又属于第一列。
但是一个位置没办法同时记录：
- 第一行是否需要置零
- 第一列是否需要置零
所以让：
```java
matrix[0][0]
```
负责记录第一行是否需要置零。
然后额外使用：
```java
boolean firstColZero = false;
```
专门记录第一列原本是否存在0。

整个流程就是：
先遍历矩阵，找到原始 0，然后利用第一列和第一行进行标记。
再根据第一行和第一列的标记，处理矩阵的内部区域。
最后再单独处理第一行和第一列。
这道题的核心地方就是：
```
第一列记录那些行清零
第一行记录那些列要请零
```
而firstColZero 是因为matrix[0][0]不能同时记录第一行和第一列俩个状态，所以专门用来记录第一列是否需要清零。
一句话总结就是：
不能边遍历边置零，所以先用第一行和第一列当作标记数组，第一列标记行，第一行标记列，最后根据标记统一置零，第一列再用 firstColZero 单独记录。
