
## 解题代码
```java
class Solution {

	public int[] twoSum(int[] nums, int target) {
	
		Map<Integer,Integer> map = new HashMap<>();
		
		  
		
		for(int i = 0; i < nums.length; i++) {
		
			int key = target - nums[i]; // 差值
			
			if(map.containsKey(key)) {
			
				return new int[]{map.get(key), i};
		
			}
		
			map.put(nums[i], i);
		
		}
		
		return new int[0];
	
	}

}
```

## 解题思路
我的理解的话就是，利用一个HashMap，key：数组中的元素，vlaue：元素在数组中的索引位置。
一个for循环遍历数组，用目标值减去当前遍历到的元素，拿到这个差值去HashMap中找，看是否存在，如果不存在，则不用管，直接将当前元素放入 HashMap。
如果存在，则说明找到了：俩数之和；因为目标值 - nums[i] = map.get(目标值 - nums[i])，也就是说nums[i] + map中存储的那个数就是目标值，所以只需要将map中存储的那个key获取到对应的value（也就是原始数组中的索引位置）再加上当前值nums[i] 的索引 i，就是要找的那俩个数。
