
## 解题代码
```java
class Solution{
	public List<Integer> findAnagrams(String s, String p) {
		List<Integer> result = new ArrayList<>();
		int sLen = s.length(), pLen = p.length();
		
		if(slen < plen) return result;
		
		int[] pCount = new int[26];
		int[] windowsCount = new int[26];
		
		for(char c : p.toCharArray()) {
			pCount[c - 'a']++;
		}
		
		int left = 0;
		for(int right = 0; right < sLen; right++) {
			windowCount[s.charAt(right) - 'a']++;
			
			if(right - left + 1 > pLen) {
				windowsCount[s.charAt(left) - 'a']--;
				left++;
			}
			
			if(right - left + 1 == pLen) {
				if(Arrays.equals(pCount, windowCount)) {
					result.add(left);
				}
			}
		}
		return result;
	}
}
```

## 解题思路
这道题的核心解题思路，就是滑动窗口，但是这道题的窗口大小是固定的。
滑动窗口的大小也就是pLen，这很好理解。
这道题主要使用数组统计窗口中字符出现的次数，如果出现一个，就根据ASCII码对应在数组位置上+1。移除则 -1 即可。
然后就是不断的移动窗口，right 向右移动一下，就判断一下当前的窗口大小是否超出了pLen，如果超出了的话就将最左侧left上的字符移除窗口，然后left向右移动一下。
如果当前窗口大小刚好等于 pLen 的话，就进行判断，当前窗口中的字符数组和 p 字符串中所需的字符数量是否一致，一致的话说明就找到了一个，此时将窗口的最左侧，也就是 left 加入结果集合中。
