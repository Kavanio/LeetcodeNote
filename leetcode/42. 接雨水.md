
## 解题代码
```java
class Solution{
	public int trap(int[] height) {
		int sum = 0;
		int left_max = 0, right_max = 0;
		int left = 0, right = height.length - 1;
		
		while(left < right) {			
			if(height[left] < height[right]) {
				left_max = Math.max(left_max,height[left]);
				sum += left_max - height[left];
				left++;
			} else {
				right_max = Math.max(right_max,height[right]);
				sum += right_max - height[right];
				right--;
			}
		}
		
		return sum;
	}
}
```

## 解题思路
> 双指针解题方法、木桶效应

1. 使用俩个变量作为前后指针，在数组的最俩侧，然后俩个指针向中间夹逼，并且再使用俩个变量，分别记录左侧的最高柱子和右侧的最高柱子
2. 循环开始，循环结束的条件是，左右指针相遇
3. 更新左右俩侧的最高柱子的值
4. 始终以最矮的那一次的最高柱子，进行计算，因为木桶效应，需要以最矮的那一块板为条件
5. 使用一侧记录的最高柱子的值减去当前柱子的值，累加到结果中，然后再进行下一次循环

---
一个位置上能接到多少水，取决于左右俩侧的柱子高度，还有左右俩侧最高的柱子。
例如左侧某一个位置上能接多少水，就是最高的柱子 - 当前柱子高度。
