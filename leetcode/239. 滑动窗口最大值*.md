	
## 解题代码
```java
public Solution {
	public int[] maxSlidingWindow(int[] nums, int k) {
		Deque<Integer> deque = new ArrayDeque<>();
		int n = nums.length;
		int[] result = new int[n-k+1];
		int index = 0;
		
		for(int right = 0; right < n; right++) {
			// 删除已经离开窗口的元素
			while(!deque.isEmpty() && deque.peekFirst() < right - k + 1) {
				deque.pollFirst();
			}
			
			// 删除比当前元素小的元素
			while(!deque.isEmpty() && nums[deque.peekLast()] < nums[right]) {
				deque.pollLast();
			}
			
			// 将当前元素索引加入队列
			deque.offerLast(right);
			
			// 当窗口形成之后，队头就是最大值
			if(right >= k - 1) {
				result[index++] = nums[deque.peekFirst()];
			}
		}
		
		return result;
	}
}
```

## 解题思路
这道题的核心解题思路，就是利用单调队列来维护当前滑动窗口中的最大值。
因为窗口大小是固定的，所以每次 right 向右移动的时候，先判断队头元素是否已经超出来当前窗口的左边界，如果超出了，就将队头移除。
然后判断当前元素和队尾的大小，如果当前元素比队尾元素大，就不断删除队尾，因为这些元素不仅比当前元素小，而且还比当前元素更早进入窗口，后面也不可能再成为最大值。
处理完成之后，将当前元素的索引加入队尾。这样就可以保证队列中的元素始终是从大到小排列的，所以当窗口形成之后，队头对应的元素就是当前窗口中的最大值，将它加入结果数组即可。
一句话总结就是：过期的从队头删除，比当前元素小的从队尾删除，当前元素加入队尾，窗口形成后直接取队头作为最大值。

---
队头中始终维护的是滑动窗口的最大值。
当滑动窗口向右滑动一位的时候，哪一位数，想要加入队列需要俩重判断：
1. 判断是否越界，也就是滑动窗口是否 == k，知道滑动窗口的右边界之后，可以计算得出窗口的左边界，所以我们只需要判断队头上的值，对应的也就是原始数组的索引值是否小于了窗口的左边界，如果小于了，那么就需要移除队头元素了。
2. 删除队列中比当前元素小的元素，也就是从队列中的队尾开始判断，只要是比当前元素小的都可以直接删除pollLast()，因为窗口中已经出现了比他们要打的元素，所以他们不可能是窗口中的最大值，所以可以直接删除，只维护队头保持为最大值。

当窗口成形之后，判断条件是：right >= k - 1，当窗口有边界大于 k - 1的时候，窗口就已经成形了，所以之后每次右移一位，窗口始终都不会变。
最后直接取出队头，他就是窗口中的最大值，放入结果数组中即可。
