
## 解题代码
```java
public Solution {
	public int[][] merge(int[][] intervals) {
		
		// 按照左断点进行排序
		Arrays.sort(intervsals, (a, b) -> Integer.compare(a[0], b[0]));
	
		List<int[]> result = new ArrayList<>();
		
		// 当前正在合并的区间
		int[] current = intervals[0];
		
		for(int i = 1; i < intervals.length; i++) {
			int[] next = intervals[i];
			
			// 有重叠
			// 下一个区间的左端点 <= 当区间的右端点，说明可以合并
			if(next[0] <= current[1]) {
			// 扩大右边界
				current[1] = Math.max(current[1], next[1]);
			} else {
				// 没有重叠，current 已经确定
				result.add(current);
				// 开启下一个区间
				current = next;
			}
		}
		
		// 最后一个区间不能忘记
		result.add(current);
		return result.toArray(new int[result.size()][]);
	}
}
```

## 解题思路
这道题的核心解题思路就是：先按照每个区间的左端点从小到大排序，然后依次判断好买呢的区间能不能和当前区间合并。
如果：next 区间的左端点 ≦ current 区间的右端点
说明下一个区间的起点还在当前区间范围内，俩个区间有重叠，就更新当前区间的右边界。
如果不能合并，就说明当前区间已经确定啦，就把它加入答案，然后让 current 指向下一个区间继续判断。
一句话总计就是：先按照左端点排序，能接上就扩大右边界，接不上就把当前区间存下来。
