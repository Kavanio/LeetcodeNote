
## 解题代码
```java
class Solution {
	public boolean isSymmetric(TreeNode root) {
		if(root == null) {
			return true;
		}
		
		return check(root.left, root.right);
	}
	
	private boolean check(TreeNode left, TreeNode right) {
		// 俩边都会空说明对称
		if(left == null && right == null) {
			return true;
		}
		
		// 一边为空，则说明不对称
		if(left == null || right == null) {
			return false;
		}
		
		// 俩遍节点值不同，不对称
		if(left.val != right.val) {
			return false;
		}
		
		// 外侧节点相比较，内侧节点相比较
		return check(left.left, right.right)
			&& check(left.right, right.left);
	}
}
```

## 解题思路
核心思路就是：**判断整棵树是否对称的问题，拆分成判断俩个子树是否互为镜像的问题。**
首先，从根节点的左右俩个孩子开始比较。
如果这俩个节点值相同，还不能说明整棵树对称，因为下面可能还存在不对称的情况。
因此，需要继续比较他们的子节点。
这里的关键是比较方向：
- 左子树的左孩子，对应右子树的右孩子
- 左子树的右孩子，对应右子树的左孩子
也就是 **外侧和外侧比较，内侧和内侧比较**，而不是简单的左边和左边比较。
每次递归都遵循这个规则，不断向下检查。
递归终止条件：
1. 俩个节点都是 null：说明对应位置都没有节点了，返回 ture。
2. 只有一个节点是null：说明结构不对称，返回 false。
3. 俩个节点的值不相同：返回 false。
4. 俩个节点的值相同：继续递归检查他们的子节点。

```
          1
        /   \
       2     2
      /       \
     3         3
    /           \
   4             4
```
```
check(2, 2)
    |
    |-- check(3, 3)
    |       |
    |       |-- check(4, 4)
    |       |       |
    |       |       |-- check(null, null) → true
    |       |       |-- check(null, null) → true
    |       |       |
    |       |       └── 返回 true
    |       |
    |       |-- check(null, null) → true
    |       |
    |       └── 返回 true
    |
    |-- check(null, null) → true
    |
    └── 返回 true
```
