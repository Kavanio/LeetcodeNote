
## 解题代码
```java
class Solution {
	public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
		ListNode pA = headA;
		ListNode pB = headB;
		
		while(pA != pB) {
			pA = (pA == null) ? headB : pA.next;
			pB = (pB == null) ? headA : pB.next;
		}
		
		return pA;
	}
}
```

## 解题思路
这道题的核心思路就是：利用双指针，消除俩个链表的长度差。
假设：
链表A：独立部分的长度是 a，公共部分的长度：c
链表B：独立部分的长度是 b，公共部分的长度同样是：c
那么链表A的长度就是：a + c；链表B的长度就是：b + c。
此时可以让A走完整个链表的时候会到B链表的头节点，然后继续往后走，同样链表B也是如果。
为什么这样呢？
因为链表A走的的长度是：a + c，然后再回去走链表B的独立部分，那么总长度就是：a + c + b；
而链表B则是：b + c + a。
此时我们发现俩个链表的长度相同了，那么他们一定会在终点相遇。
