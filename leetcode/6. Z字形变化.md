
## 解题代码
```java
public String convert(String s, int numRows) {
	if(numRows == 1) return s;
	
	StringBuilder[] rows = new StringBuilder(numRows);
	for(int i = 0; i < numRows; i++) {
		rows[i] = new StringBuilder();
	}
	
	int currr_row = 0;
	int direction = 1;
	
	for(char c : s.toCharArray()) {
		rows[curr_row].append(c);
		
		if(curr_now == 0) {
			direction = 1;
		} else if(curr_now == numRows - 1) {
			direction = -1;
		}
		
		curr_now += direction;
	}
	
	StringBuilder result = new StringBuilder();
	for(StringBuilder sb : rows) {
		result.append(sb);
	}
	
	return result.toString();
}
```

## 解题思路
> 用一个数组来存储每一行的字符，通过控制行号的增减来模拟向下走和斜向上走
> 1. 初始化创建 numRows 个StringBuilder对象
> 2. 遍历字符中每个字符
> 3. 然后将当前字符添加到对应数组索引中位置上的 StringBuilder
> 4. 添加完成之后判断当前是否到达转折点
> 	1. 俩个转折点：到达最顶部、到达最底部
> 	2. 到达最顶部只需要将，控制方向的变量 direction 改为 1，即可
> 	3. 到达最底部，则将其改为 -1
> 5. 然后更新行号，例如当前到达最底部是 3，则更新完行号之后就变成了 2，所以下次循环当前字符就会添加到数组中第二个 StringBuilder 中
> 6. 最后拼接 StringBuilder 返回
