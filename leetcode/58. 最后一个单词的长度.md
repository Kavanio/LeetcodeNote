
## 解题代码
```java
	public int lengthOfLastWord(String s) {

		int index = s.length() - 1;
		
		while(s.charAt(index) == ' ') {
		
			index--;
	
		}
	
	  
	
		int word_length = 0;
		
		while(index >= 0 && s.charAt(index) != ' ') {
		
			word_length++;
			
			index--;
		
		}
	
	  
	
		return word_length;
	
	}
```

## 解题思路
> 既然题目中说是找最后一个单词的长度，所以我们可以采用从后向前遍历的方法。

1. 我们可以先定义一个指针，这个指针从后向前寻找字符中不等于空字符的索引位置，也就是说找到最后一个不为空字符的，单词word的屁股
2. 找到这个位置就好办了，同样我们只需要定一个变量记录最后一个单词的长度，然后从后向前遍历即可
3. 循环停止的条件就是，遇到一个空字符
