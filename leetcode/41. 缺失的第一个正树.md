## 解题代码
```java
public Solution {
	public int firstMissingPositive(int[] nums) {
	
		int n = nums.length;
		
		for(int i = 0; i < n; i++) {
			while(
				nums[i] > 0 &&
				nums[i] <= n &&
				nums[nums[i] - 1] != nums[i]
			) {
				int targetIndex = nums[i] - 1;
				
				int temp = nums[i];
				nums[i] = nums[targetIndex];
				nums[targetIndex] = temp;
			}
		}
		
		for(int i = 0; i < n; i++) {
			if(nums[i] != i + 1) {
				return i + 1;
			}
		}
		
		return n + 1;
	}
}
```

## 解题思路
这道题的核心不是去找数组中间“断掉”的数字，而是永远冲正整数 1 开始找第一个没有出现的数。
因为数组的长度是 n，答案一定在 1 ～ n + 1 之间，所以只需要处理 1 ～ n 的数字，负数、0和大于n的数字都可以忽略。
关键思路是把数组本身当成 Hash 表，让数字 x 放到下标 x - 1 的位置，比如 1 -> 0 , 2 -> 1 , 3 -> 2。
使用while是因为一次交换之后，当前位置可能又换回来一个需要继续归位的数字；同时判断目标位置是不是已经存在相同的数字，避免重复元素造成死循环。
整理完之后从左到右检查，第一个满足 nums[i] != i + 1 的位置，i + 1 就是答案；
如果全部对应正确，则返回 n + 1.
一句话就是：让数组 x 回到 下标 x - 1，第一个没坐对位置的数字就是缺失的最小正整数。
