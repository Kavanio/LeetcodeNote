
## 解题代码
```java
class Solution {
	public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
		ListNode dump = ListNode(0); // 创建虚拟头节点
		ListNode tail = dump;
		
		while(list1 != null && list2 != null) {
		
			if(list1.val <= list2.val) {
				tail.next = list1;
				list1 = list1.next;
			} else {
				tail.next = list2;
				list2 = list2.next;
			}
			
			// 尾指针向后移动
			tail = tail.next;
		
		}
		
		if(list1 != null){
			tail.next = list1;
		} else {
			tail.next - list2;
		}
		
		return dump.next; // 返回真实的头节点
	}
}
```


## 解题思路
这道题的核心就是利用俩个指针，反复比较俩条链表当前节点的值，把较小的节点接到结果链表后面。在移动对应指针。
使用 `dump`虚拟头节点可以避免单独处理结果链表的第一个节点，使用 `tail` 维护结果链表的末尾；
当其中一条链表遍历结束的时候，直接街上另一条链表的剩余部分即可。（因为俩条链表都是升序排列的，所以剩余部分也一定是升序排列的，可以直接接上）。
整个过程只调整节点指针，不需要重新创建节点。
