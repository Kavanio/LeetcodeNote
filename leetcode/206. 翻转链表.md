
## 解题代码
```java
class Solution {
	public ListNode reverseList(ListNode head) {
		if(head == null || head.next == null) return head;
		
		ListNode newHead = reverseList(head.next);
		
		head.next.next = head;
		head.next = null;
		
		return newHead;
	}
}
```

## 解题思路
![[Pasted image 20261004102058.png]]

核心思路：递归的关键是先递归到链表的最后一个节点，再从后往前修改指针。
比如处理 1 时，先让 2 -> 3 -> 4 -> 5 自己翻转，等回来后再让 2.next = 1，也就是代码里的 head.next.next = head，最后用 head.next = null 断掉原来的 1 -> 2，防止形成环。递归最底层返回的 5 就是新的头节点 newHead，之后每一层都把它继续返回。
