	
## 解题代码
```java
class Solution{
	public int lengthOfLongestSubstring(String s) {
		Set<Character> set = new HashSet<>();
		int left = 0;
		int maxLength = 0;
		
		for(int right = 0; right < s.length(); right++){
			Character current_s = s.charAt(right);
			while(set.contains(current_s)) {
				set.remove(s.charAt(left));
				left++;
			}
			
			set.add(current_s);
			
			maxLenght = Math.max(maxLength, (right - left + 1));
		}
		
		return maxLength;
	}
}
```

## 解题思路
这道题的核心解题思路就是“**双指针**+**滑动窗口**”，并且利用***Set***集合统计字符出现的次数。
首先定义一个Set集合，里面存放的是当前正在找的无重复字符的子串。
然后定义俩个指针，刚开始都在起始位置上。
right 指针不断的向后去寻找新的字符，当发现一个字符不在Set集合中，就说明这个字符之前没有出现过，可以放入Set集合中，统计为一个子串中的一位。
如果发现当前的字符已经出现在Set集合中了，说明重复了。
此时需要开始移动left指针，并将重复的字符从Set集合中移除掉。

---
for循环中间为什么要使用while循环呢？
我一开始认为，只加一个if，然后判断一下，去除掉前一个字符；但事实上这样是完全错误的。
首先，因为我们要去掉的是一个重复的字符，例如：“abcb”，要去掉b，单独去掉a，是没有用的。
所以我们必须要使用while循环去周到重复的字符在set中存在的位置。
**那么这样就可能为了找到一个重复的字符，然后去掉了前面不重复的字符。**
这又是怎么回事呢？
因为题目要求的是一个**子串**，子串的意思是他必须是连续的，连续的意思是指在原始数组中必须是连续的。
如果重复的字符在中间的话（例如：“abcb”，要去掉“b“），如果只去掉”b”，留下：“acb”，那么这个字符串并不是一个子串，也就是他不是连续的，所以才需要把前面不重复的字符也去掉。
