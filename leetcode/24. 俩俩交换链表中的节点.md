
## 解题代码
```java
class Solution {
	public ListNode swapPairs(ListNode head) {
		// 递归终止条件
		if(head == null || head.next == null) {
			return head;
		}
		
		ListNode first = head;
		ListNode second = head.next;
		
		ListNode next = swapPairs(second.next);
		
		first.next = next;
		second.next = first;
		
		return second;
	}
}
```

## 解题思路
![[Pasted image 20261012090906.png]]

这道题要求将链表中相邻俩个节点交换位置，不能直接交换节点的值。
我们使用递归来解决，因为每次需要处理的其实都是相同的问题：交换当前俩个节点，再处理剩下的链表。
我们可以先找到当前的`first`和`second`，然后通过`swapPairs(second.next)`递归交换后面的节点，等递归返回时，拿到的就是后半段交换后的新头节点`next`。
接着让 `first.next = next`，把当前第一个节点连接到后半段，再让 `second.next = first`，染完成当前俩个节点的交换，最后返回 second，因为它已经成为了新的头节点。递归结束条件时链表为空或者只剩下一个节点，此时不需要交换，直接返回即可。
**核心就是先递归处理后面的链表，再利用返回的新头节点，把当前俩个节点交换并连接起来**
