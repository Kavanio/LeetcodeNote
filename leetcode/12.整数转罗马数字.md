## 解题代码
```java
class Solution {

	public String intToRoman(int num) {

	// 1. 建立“面额表”
	
	// 我们把所有可能的罗马数字“积木块”按数值从大到小排好队。
	
	// 特别注意：4、9、40、90 这种特殊的减法组合，也要当成一个独立的整体放进去！
	
	int[] values = {1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1};
	
	String[] symbols ={"M","CM","D","CD","C","XC","L","XL","X","IX","V","IV","I"};

  

	// 用于记录结果字符，比String高效
	
	StringBuilder result = new StringBuilder();
	
	  
	
	for(int i = 0; i < values.length; i++) {
		// 当前数字 >= 当前面额，说面可以拿走当前这个面额，也就是values[i]
		
		while(num >= values[i]){
		
			// 根据当前取出的这个面额，去获取对呀的字符，然后拼接进结果字符中
			
			result.append(symbols[i]);
			
			// 拼接完成之后，需要将num - 刚才取出的面额
			
			num -= values[i];
		
		}
	
	}
		return result.toString();
	
	}

}
```

## 解题思路
> 题目核心就是需要处理一下“特殊减法规则”  4 -> IV 9 -> IX
核心思路：贪心算法
- 先确定13个固定的面额和对呀的罗马字符
- 然后循环遍历面额数组
- 用当前数字num和面额数组中每个数一一比较
- 如果当前数字num >= 当前面额数字中的一个数的时候
* example：
	* 58 >= 50
- 所以此时我们就需要从面额数组中取出50这个面额
- 然后去对应的罗马字符数组中根据对应的索引找到对应的罗马字符，然后拼接到结果字符中
- 当取出一个面额之后，因为已经取出values[i]的面额了，所以就需要用num减去这个面额，然后循环继续
