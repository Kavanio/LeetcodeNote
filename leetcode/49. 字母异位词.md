
## 解题代码
```java
class Solution {

public List<List<String>> groupAnagrams(String[] strs) {

	HashMap<String, List<String>> map = new HashMap<>();
	
	  
	
		for(String s : strs) {
		
			char[] char_arr = s.toCharArray();
			
			Arrays.sort(char_arr);
			
			String key = new String(char_arr);
			
			  
			
			map.computeIfAbsent(key, k -> new ArrayList<>())
			
				.add(s);
		
		}
		
		  
		
		return new ArrayList<>(map.values());
	
	}

}
```

## 解题思路
> 题目中说：“字母异位词”，意思就是说，一个单词，他们的组成部分是相同的，但是每个字符组成的顺序是不一致的。
> 例如："abd" and "bda" 这俩个就属于字母异位词

搞清楚了什么是字母异位词之后，关于这道题我们还是可以使用一个 HashMap。
key：存储的是排序过后的单词
> 为什么要排序？
> 因为排序过后每个字符都是会按照顺序排列，这主要是因为每个英文字符会对应一个ASCII码。
> 例如：a是97，A是65.
> 因为字母异位词中每个单词虽然不一样，但是组成的字符都是一样的，所以通过排列后组成的单词必定是同一个

value：存储的是一个列表，里面存放的所有的字母异位词

搞清楚 HashMap 中存储的时候，之后就简单了。
只需要一个for 循环，遍历一次字符串数组，然后将每一个字符串转换成字节数组，然后再排序，再组成一个新的字符串，以这个新的字符串为key去 HashMap 中查询，如果存在，则将原始字符串插入列表中，如果不存在则创建一个空的列表。
最后返回即可。
