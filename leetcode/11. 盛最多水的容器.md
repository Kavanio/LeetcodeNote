
## 解题代码
```java
class Solution {

	public int maxArea(int[] height) {
		int left = 0;
		int right = height.length - 1;
		int maxArea = 0;
		
		while(left < right) {
		
			int width = right - left;
			
			int h = Math.min(height[left], height[right]);
			
			int currentArea = width * h;
			
			maxArea = Math.max(maxArea, currentArea);
			
			if(height[left] < height[right]) {
			
				left++;
			
			} else {
			
				right--;
			
			}
		}
		return maxArea;
	}
}
```

## 解题思路
这道题的核心解题思路就是利用双指针，一个指针在数组的最左侧，一个在最右侧。
然后来个指针向中间收拢，寻找最大面积。
并且每次移动都是优先移动最短的那个水柱，因为一个容器的最大盛水量取决于最短的那个柱子，所以计算面积的公式就是：俩根柱子之间的宽度 ✖️ 最短那根柱子的高度。
并且每次移动也是优先移动最短的那根柱子，去寻找更长的柱子。
