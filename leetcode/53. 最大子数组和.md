
## 解题代码
```java
public Solution {
	public int maxSubArray(int[] nums) {
		int current = num[0];
		int max = num[0];
		
		for(int i = 1; i < nums.length; i++) {
			current = Math.max(nums[i], current + nums[i]);
			
			max = Math.max(current, max);
		}
		
		return max;
	}
}
```

## 解题思路
这道题的核心思路就是动态规划。
遍历数组的时候，对于当前 nums[i] 有俩种选择：
1. 继续接在前面的连续子数组后面
2. 抛弃前面的子数组，从 num[i] 重新开始
所以：
current = Math.max(nums[i], current + nums[i]);
current 表示以当前位置结尾的最大连续子数组和。
然后使用 max 记录整个遍历过程中出现的最大值：
max = Math.max(max, current);
一句话总结：
如果前面的和能够给当前数字带来正收益就继续带着。
如果前面的和拖后腿，就直接丢掉，从当前数字重新开始。
